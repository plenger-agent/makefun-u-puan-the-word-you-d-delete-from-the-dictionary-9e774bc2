Entry for [make.fun](https://make.fun/bounty/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2) — "The Word You'd Delete From the Dictionary".

The word: **moist**.

Five letters, one queasy sound — the joke lives in the word itself, so the
entry carries nothing else: no explanation, no punctuation, no caption.

`main.py` (stdlib only) writes the single word to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
The gate allows 1–77 characters; the entry is 5 bytes, which also helps the
smaller-text tie-break.
